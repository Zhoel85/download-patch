FINAL SECURITY REVIEW

- Auth legacy tetap menggunakan session id + hak_akses, canonical permission tetap berjalan paralel.
- CSRF tetap aktif.
- Password MD5 legacy terdeteksi sebagai warning sampai seluruh akun termigrasi.
- Rate limit melindungi finalisasi saksi, incident, verifikasi, import apply/rollback dan export.
- Authenticated response diberi Cache-Control no-store.
- X-Content-Type-Options nosniff.
- X-Frame-Options SAMEORIGIN.
- Referrer-Policy same-origin.
- Folder application/uploads sensitif deny-all.
- Folder assets/uploads publik menolak script executable.
- Big Screen tetap token read-only.
- DPT tidak boleh menyimpan preferensi politik individu.
- Real Count wajib berlabel internal/hasil sementara.
