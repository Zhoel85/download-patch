CONCURRENCY TEST — REAL COUNT

TUJUAN
Memastikan satu Event+TPS hanya memiliki satu proses finalisasi otoritatif.

SKENARIO A
1. Siapkan 2 akun saksi berbeda pada Event dan TPS yang sama.
2. Buka halaman hasil pada dua browser/perangkat.
3. Isi hasil valid pada keduanya.
4. Tekan Finalisasi hampir bersamaan.

HASIL WAJIB
- Hanya satu witness memperoleh claim Event+TPS.
- Request lain menerima HTTP 409 / Finalisasi TPS Terkunci.
- real_count_tps_registry hanya punya satu row untuk Event+TPS.
- witness_result_headers tidak boleh memiliki >1 status FINALIZED/VALIDATED/VERIFIED untuk Event+TPS.

SQL VERIFIKASI
SELECT event_id,id_tps,COUNT(*) total
FROM witness_result_headers
WHERE status IN ('FINALIZED','VALIDATED','VERIFIED')
GROUP BY event_id,id_tps
HAVING COUNT(*)>1;

HASIL WAJIB: 0 row.
